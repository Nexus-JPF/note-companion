# Note Companion

Turns recordings and other material into organized notes in an Obsidian vault, and from those notes into material for studying.

## Language

### Study notes

**Study note**:
A note generated from another note so the user can revise its content. It is the umbrella term for every study format and is always linked both ways with the note it came from.
_Avoid_: Study guide, revision note, review note

**Flashcards**:
A study note made of question-and-answer cards, one fact per card, where the answer is revealed on click.
_Avoid_: Cards note, flash cards (two words)

**Quiz**:
A study note made of multiple-choice questions, each with the correct option and a short explanation revealed on click. Not scored in its first version.
_Avoid_: Test, exam, practice exam

### Templates

**Template**:
A note in the vault's templates folder holding instructions for the AI, used to format or generate a note.
_Avoid_: Prompt, preset

**Default template**:
A template the plugin ships and writes into the vault when it is missing.
_Avoid_: Bundled template, built-in template, stock template

**Custom template**:
A template the user made, renamed or copied. The plugin never changes it.
_Avoid_: User template

**Outdated template**:
A default template whose text is an unedited copy of an older release's default.
_Avoid_: Stale template

**Edited template**:
A default template whose text, ignoring line endings and trailing whitespace, matches no release's default.
_Avoid_: Modified template, customized template
