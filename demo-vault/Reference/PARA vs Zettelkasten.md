# PARA vs Zettelkasten

Both are organising systems. They answer different questions, which is why the
comparison is usually framed badly.

## PARA

Projects, Areas, Resources, Archive. Organises by **actionability** — how soon
does this matter, and to what commitment does it belong.

Strength: a note's location is derivable from a question you can always answer
("what is this for?"). Cheap to maintain.

Weakness: connections between notes are incidental. Two related ideas in
different projects never meet.

## Zettelkasten

Atomic notes, densely linked, no folder hierarchy of consequence. Organises by
**relatedness**.

Strength: connections are the point, so the system produces surprises.

Weakness: expensive. Every note carries a filing decision that has no obvious
answer, and the value only appears at scale, long after the cost is paid.

## The honest comparison

PARA is a system for *working*. Zettelkasten is a system for *thinking*. Most
people trying to choose are actually working, and should stop reading about
Zettelkasten.

Hybrid in practice: PARA folders for anything with a deadline, a flat linked
area for anything without one.
